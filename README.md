# Eastside Trails

Filterable map of bike-friendly trails (paved or groomed gravel) within 30 miles of
Newcastle, WA, aimed at finding easy rides for a new rider on a class 1/2 e-bike.

- Grade profiles computed from USGS 3DEP elevation data
- GPX per trail segment
- Parking points with addresses (lat/lon fallback) and Discover Pass flags
- Ride generator with one-way and round-trip modes

Sources: Washington Trails Association and the managing trail authorities first,
OpenStreetMap (© OpenStreetMap contributors, ODbL) as secondary.

Work in progress.
